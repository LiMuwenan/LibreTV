LibreTV 部署包使用说明
=====================

一、环境要求
- Windows 10/11
- Node.js 20 或更高版本（未安装请先到 https://nodejs.org/ 下载安装 LTS 版）

二、安装
1. 将压缩包解压到任意目录（路径尽量不要包含中文和空格）
2. 双击运行 install.cmd，等待依赖安装与构建完成（约 2~5 分钟，视网速而定）
3. 国内网络若安装依赖慢，可先执行：
   npm config set registry https://registry.npmmirror.com

三、启动
- 双击 start.cmd 启动，浏览器访问 http://localhost:8080
- 默认访问密码：libretv123（修改 .env 中 PASSWORD= 的值，重启后生效）
- 关闭：关闭运行 start.cmd 的窗口即可
- 影视点播：首页搜索或浏览推荐；电视直播：顶部进入「直播」页（/live）

四、配置说明（.env 文件）
- PASSWORD：站点访问密码
- DEFAULT_SOURCES：预置采集源（23 个，已逐一实测可用，含美剧/英剧/日剧/韩剧等全球内容）
- DEFAULT_LIVE_SOURCES：预置直播源（4 组 M3U：国内电视 x2、港澳台及海外、全球综合），在「直播」页使用，支持测活与「仅可用」筛选
  · 范明明 IPv6 源需要本机支持 IPv6，不支持时可忽略该组
  · EPG 节目单已配置（范明明源），其余列表无节目单属正常
- 修改 .env 后重新运行 start.cmd 即可生效，无需重新构建

五、代理说明
- 部分采集源在国内直连不可达，本包内置代理支持（proxy-setup.cjs）：
  start.cmd 会自动读取系统 Internet 代理设置并传递给程序；
  若代理不可用则自动回退为直连，不会影响启动
- 如需手动指定代理（例如 Clash 的 7890 端口），在启动前设置环境变量：
  set LIBRETV_PROXY=http://127.0.0.1:7890
  或直接修改 start.cmd 中的对应位置

六、常见问题
- 搜索时部分源超时/失败：属正常现象，站点会自动对失败源做健康检查并择机降级，
  可在「设置 → 源管理」中查看每个源的健康状态并手动测活
- 修改端口：编辑 package.json 中 dev / start 的 -p 8080 参数后重新运行 start.cmd
- 采集源会随时间失效：可在「设置 → 源管理」中增删或替换源，也可重新编辑 .env

七、目录说明
- .env              配置文件（密码 + 预置采集源）
- install.cmd       安装脚本（npm install + 构建）
- start.cmd         启动脚本（自动带代理启动）
- proxy-setup.cjs   代理注入模块
- src/              LibreTV 源代码
